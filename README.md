# SCM_HW1_Bayan
Homework for SWE 442 - Software Configuration Management.
This repository is created for SWE 442 homework to demonstrate version control, branching, and change management.

 Best Practices in Software Configuration Management
- Use meaningful commit messages.
- Maintain a clear branching strategy.
- Track all changes using issues and pull requests.
- Ensure documentation is always up to date.
- Regularly review and manage project versions.
